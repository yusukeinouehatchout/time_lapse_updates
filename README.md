macOSメニューを日本語化し、「タイムラプス → 更新を確認…」を追加しました。AppBarの更新ボタンとバッジも残しています。撮影中・カメラ処理中は、どちらからも更新操作を開始できません。起動時の横幅はそのまま、縦幅は全項目が収まる高さに調整します。ディスプレイに収まらない場合はスクロールできます。

起動時に更新情報を確認し、最新版がある場合は「更新を確認」ボタンにバッジを表示します。確認だけでは更新画面やダウンロードは始まりません。アドホック署名の配布版のため、インストールはDMGから手動で行ってください。撮影を停止してアプリを終了し、DMG内の「タイムラプス.app」をApplicationsへコピーして置き換えます。公開リポジトリの配布物はURLを知る人ならダウンロードできます。過去の更新情報と配布ファイルも保持しています。
